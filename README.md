# わんポーズ

![わんポーズ — 健康 × Tech、sd2608 チームカツカレー](docs/images/topimage.png)

## 製品概要

「わんポーズ」は、デスクトップのワンちゃんが休憩のきっかけを届け、作業の振り返りを手伝うWindows向けデスクトップアプリです。

### 背景(製品開発のきっかけ、課題等）

プログラミングや勉強(もしくはSNS)に集中していると、気づかないうちに長い時間が過ぎ、休憩を後回しにしてしまうことがある人は少なくないのではないでしょうか。一方、一定間隔のタイマーだけでは、作業の途中で通知が届き、つい無視してしまいがちです。また、一度休憩を取ってしまうとその後作業に戻るのが億劫になることもよくあります。

私たちは、作業の効率を保ちつつ休憩する、というコンセプトのもと、作業の区切りに休憩を提案し、休憩後に何をしていたかを思い出せる仕組みを作りたいと考えました。

### 製品説明（具体的な製品の説明）

カメラでの顔の有無とPCの使用状況から連続在席時間を計測し、入力が止まったときやウィンドウを切り替えた後など、作業の区切りでワンちゃんが休憩を提案してくれます。

通知から「レポートを作る」を選択すると、その時点の作業履歴から作業レポートを作成します。自然に席を離れた場合もレポートを作成し作業に戻ったユーザーに表示します。記録は端末内だけで利用でき、AIを設定した場合は作業の概要や次に取り組むことの候補をまとめます。

起動時は記録を停止しており、取得する情報を確認してから開始します。起動・設定・デモの手順は[開発・実行ガイド](docs/development.md)にまとめています。

### 特長

#### 1. 作業の区切りを見つけて、わんこが休憩を提案

単純な経過時間だけでなく、無操作やウィンドウの切り替えも使って通知します。初期設定では30分から区切りを待ち、区切りがなくても35分で提案します。30分の目安の3分前には予告し、休憩へのハードルを下げてくれます。長く作業を続けたときには強調してお知らせします。かわいいワンちゃんののアニメーションで休憩のきっかけを作ります。

#### 2. 休憩前の作業を記録し、戻ったときの振り返りを支援

「レポートを作る」で即時に、自然な離席では初期設定で離席確定から5分後に、直近の作業履歴をレポートにします。AI要約は任意で、送信先への同意を得て利用します。OCRを有効にすると、取得したウィンドウの文字を作業履歴と照合し、要約の補足に使えます。

#### 3. 自分のペースに合わせて通知を調整

通知音は「犬の鳴き声」「システム音」「音なし」から選べます。休憩の目安・予告・再通知・離席判定・レポート待機など13項目の時間を別々に設定できます。除外アプリや「動きを減らす」設定にも対応しています。

### 解決出来ること

- 集中しているうちに休憩のきっかけを逃してしまうこと。
- 作業の流れに合わない通知を閉じ続けてしまうこと。
- 休憩後、作業になかなか戻れないこと。直前に何をしていたか思い出すために手間がかかること。

### 今後の展望

- UI/UXを洗練させる。
- 日ごとや週ごとの作業・休憩の振り返りを見やすくする。
- 機械学習の導入や利用者のフィードバックをもとに、通知のタイミングや伝え方を改善する。
- 骨格を推定して悪い姿勢を指摘する機能を追加する。
- Windows以外のOSへの対応を検討する。

### 注力したこと（こだわり等）

- 犬の動きや吹き出しを通じて、作業を責めずに休憩へ誘う表現にしました。アニメーションの完了を待たずに通知・レポートを表示し、操作を妨げないようにしています。
- カメラの顔検出とOCRは端末内で処理します。画像は保存・外部送信せず、AIには同意した場合だけ作業履歴やOCRの文字を送ります。URLやメールアドレスなどのマスク、除外アプリの設定、APIキーのWindows DPAPIによる暗号化も実装しました。
- 記録停止後の遅い処理結果やイベントの再送で、通知・レポートが重複したり、削除済みのデータが復活したりしないようにしました。

## 開発技術

### 活用した技術

#### API・データ

- Windows API
- MediaPipe Face Detector / BlazeFace
- Gemini API / OpenAI互換Chat Completions API
- 日本語・英語のOCRモデル

#### フレームワーク・ライブラリ・モジュール

- Tauri 2 / Rust
- React / TypeScript / Vite
- MediaPipe Tasks Vision
- Tesseract.js / xcap
- Tokio / reqwest / Serde

#### デバイス

- Windows PC（WebView2 Runtime）。
- 内蔵カメラまたはUSBカメラ。
- 通知音を再生するスピーカーまたはヘッドホン（音なしでも利用可能）。

### 独自技術

#### ハッカソンで開発した独自機能・技術

- 在席状態と作業の区切りを組み合わせた通知判定
- 作業履歴を固定してから生成するレポート
- 犬と操作領域だけに反応するデスクトップ表示
- 作業履歴と照合するOCR
