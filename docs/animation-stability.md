# ポチ・全アニメーションの安定化

このPRは入場・設定接続のPR #11の機能も含みます。全動作をまとめて取り込む場合は、このPRをレビューしてください。main ce21df3の最新UI・実カメラデモ・通知音・時間設定・リポジトリ整理を保持しています。

| 動作 | コマ数 | 再生 |
| --- | ---: | --- |
| 待機・まばたき | 8 | ループ |
| 休憩のお知らせ | 8 | 一回 |
| 伏せて休憩 | 14 | ループ |
| 作業を記録 | 8 | 一回 |
| おかえり・まばたき | 20 | 一回 |
| 振り向いて座る | 23 | 一回 |
| 伏せから起きる | 26 | 一回 |
| 座りから伏せる | 26（逆再生） | 一回 |
| 走り込んで伏せる | 107 | 起動時に一回 |

全9動作は `FramePlayback` と `useSpriteCanvas` を共用します。画像をdecodeしてから固定のcanvasへ描画し、完了通知も同じ時計で返します。読込中は前の描画を保持し、古い読込・予約フレーム・通知を無視します。同じ状態・キュー・コールバックの更新で再生をやり直しません。

通常動作の表示は170px、canvasは512pxです。`frame-registration.json` は元PNGのalpha > 32の下端です。足元を480へ合わせる最大4px（表示約1.3px）の縦補正だけを行い、横の動き・身体の形・素材は維持しています。クリック透過も描画済みフレームの補正量を使い、犬のhoverによる明るさの変化は無効です。

入場の承認済みAPNG・個別PNGは変更していません。ランタイム用に480×320のセルを等比縮小してパックし、元の経路・107コマ・25fps・4.28秒を維持します。入場終了では伏せ画面の描画を待ち、伏せを不透明で表示してから入場を外します。二層を同時に半透明にして明るさを下げる処理は使いません。入場終了後は入場図集のキャッシュを解放します。

非表示中は演出の時計を止めます。処理が詰まった場合の一度の進行は、100msと最短コマ時間の小さいほうまでに制限し、中間コマをまとめて飛ばさないようにします。この場合は演出だけ長くなります。業務計時・監視・記録・レポートの時計には影響しません。

## 検証結果

- `npm test`: 161件成功。全9動作のコマ順・ループ境界・一回完了・遅延読込・割り込み・非表示復帰・古い通知・25fpsのフリーズ後・接地補正とクリックを含みます。
- `npm run build`: TypeScriptとViteのビルド成功。
- `python scripts/audit-animation-assets.py`: 214個の元コマ、逆再生を含む240コマを検証。通常動作の空白コマなし、接地値・共有端点・ポスター一致、元GIFのハッシュ、入場全107コマのパック一致、23コマの最終静止区間の一致を確認しています。入場の0番だけは仕様どおり透明です。

この環境のブラウザーからlocalhostへの接続がタイムアウトするため、ブラウザーの描画テスト・目視・Windows実機操作は未確認です。自動検証は素材と再生ロジックの結果であり、全端末での目視合格を意味しません。配布済みアプリへ反映するには変更の取り込みと再ビルドが必要です。実行ファイルは再生成していません。
