# ポチのアニメーション描画

現在の main の表示崩れを修正する変更です。起動時の走り込み・設定時の起き上がりを追加する PR #11 とは独立しています。

GIF の内蔵再生と完了判定の時計を併用すると、動作の終わりと切替が一致しませんでした。現在は既存の透明 PNG アトラスを同じ 512×512 canvas に描画し、描画と完了通知を `SpritePlayback` で管理します。表示サイズは従来の 170px です。GIF 原本と PNG 原本は変更していません。

次の画像は decode 完了後に切り替え、それまでは描画済みの画像を保持します。古い読込・予約フレーム・完了通知は再生トークンと世代番号で無効にします。同じ待機姿勢への更新や、コールバックだけの再作成では再生をやり直しません。

非表示中は再生時間を進めず、復帰時は表示中のポーズから再開します。前景で処理が詰まった場合は、一度の進行を最大100msに制限します。その場合は再生時間が延びますが、業務の時計や記録時間には影響しません。

`frame-registration.json` は元 PNG の各タイルの alpha > 32 の下端（排他的座標）です。下端を480へ合わせる最大4pxの縦補正だけを適用し、横方向の動きや身体の形は変えません。170px表示では最大約1.3pxです。PNG を交換した場合はこの値も再計測してください。クリック透過も描画済みフレームの補正量を使います。犬の hover による明るさの変化は無効にしています。

## 検証

- `npm test`: 134件成功。正逆再生、全フレームの描画順、最終フレームと一度だけの完了、遅延読込、古いフレーム、非表示からの復帰、停止・失敗・動きを減らす設定、接地補正後のクリック判定を含みます。
- `npm run build`: TypeScript と Vite のビルド成功。
- 既存のバックエンド・記録・レポート・UIレイアウトは維持しています。

この作業環境のブラウザーから localhost に接続できないため、ブラウザーの描画テスト・目視・Windows実機操作は未確認です。実行ファイルは再ビルドしていません。配布済みアプリへ反映するには、この変更の取り込みと新しいビルドが必要です。

手動確認は `npm run dev:mock` を実行後、次のページで行えます。

1. `http://localhost:1420/tests/browser/animation-stability-smoke.html`: 全動作を自動再生し、空白フレーム、canvas の交換、表示位置・寸法の変化、完了通知の重複を検証。PASS後のボタンでも再生できます。
2. `http://localhost:1420/tests/browser/pet-ui-smoke.html`: 既存のメニュー・設定・記録・レポートの操作確認。
3. `http://localhost:1420/tests/browser/window-click-through-smoke.html`: 現在表示している PNG の透明画素とクリック領域の照合。
4. `npm run tauri dev`: 休憩→起き上がり→おかえり、マウスを犬の輪郭に置いた状態、ウィンドウを隠してから戻した状態を目視確認し、ドラッグとクリック透過も確認してください。
