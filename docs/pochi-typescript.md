# ポチ：TypeScript版の操作と実装

指定された手動の作業・休憩フローをReact + TypeScriptで実装し、通常起動の入口へ接続しています。C#、WPF、C#の実行ファイルは必要ありません。既存のセンサー・AI用の共通契約とモックはそのまま残しています。

## 起動

```powershell
npm ci
npm run dev
```

表示されたローカルURLを開きます。通常のVite設定は1420番です。ブラウザーだけで作業の記録からレポートまで操作できます。`?demo=1` を付けると作業12秒、休憩目安8秒、No後8秒の短縮時間で確認できます。デモ表示は画面上に明記します。

Windowsデスクトップ版は、Rust/MSVC/WebView2を備えた環境で起動します。

```powershell
npm run tauri dev
```

配布用は `npm run tauri build`。透過・枠なし・置頂のウィンドウ、移動ボタン、閉じる前のレポート表示を設定済みです。macOS/Linuxのネイティブ動作は未検証です。

## 指定された11段階

| 操作 | 動作 |
| --- | --- |
| 1. ダブルクリック | 設定を開き「保存してもどる」で確定。単クリックの遅延処理を取り消す |
| 2. 作業の記録 | 作業／勉強と作業名を入力。開始ボタン、またはもう一度ポチを単クリック |
| 3. お座り→伏せ | 採用済みの起き上がりPNG列と表示時間を逆順に再生 |
| 4. 作業中／休憩中 | しっぽ・耳・呼吸を含む伏せループを再生 |
| 5. 伏せ→お座り | 踏み替え・向きの変化がある `rest_to_sit` 第3版を再生 |
| 6–7. 休憩の提案 | 通知動作、吹き出し、はい／いいえの選択肢を表示 |
| 8–9. はい | 休憩回数を1回増やし、進捗・困りごとを保存。メモ入力や重複クリックで回数を増やさない |
| 10. いいえ | 「休憩も忘れないでね」と表示。休憩回数を増やさず設定時間後に再通知 |
| 11. 終了 | 作業と休憩を確定してローカル保存。レポートをアプリ内に表示 |

「戻ったよ」で休憩を終え、起き上がり→まばたきを含む歓迎を1回再生し、続ける操作を待ちます。「ひとまわり」は独立した一周→着席の動作です。姿勢遷移の途中で別の操作をしても、現在の姿勢遷移を終えてから次へ進み、古い完了コールバックは無視します。

## ソースの入口

| ファイル | 責務 |
| --- | --- |
| `src/pochi/model.ts` | 作業・休憩の状態、時間、Yes/No、設定、記録データと純粋な状態遷移 |
| `src/pochi/repository.ts` | 保存データの検証、localStorage、予備コピー、二重起動時の上書き防止 |
| `src/pochi/controller.ts` | 時計、画面と動作の接続、通知、保存、終了・復元 |
| `src/pochi/animation.ts` | フレーム時間、逆再生、連続再生、割り込み |
| `src/pochi/PochiSprite.tsx` | 透過スプライトシートの再生と画像失敗時の静止画 |
| `src/pochi/PochiApp.tsx` | 日本語UI、設定、作業入力、休憩メモ、レポート |
| `src/pochi/desktop.ts` | Tauriの置頂・移動・閉じるAPI。ブラウザーでは呼び出さない |
| `src/pochi/atlases.json` | 7動作・107フレームの順序、寸法、各フレームの表示時間 |
| `public/pet/pochi/` | 7枚の透過PNGアトラス、2枚の静止画、チャイム |
| `tests/pochi.test.mjs` | フロー、計時、保存・復元、割り込み、素材の自動テスト |

アトラスは採用済みの107枚のRGBA画像を4列のシートへ並べたものです。全フレームの画素を元画像と照合済みで、絵や動きの内容を変更していません。`sit_to_rest` は `rest_to_sit` のフレームと時間を逆順で利用します。GIFを伸縮して姿勢を変える処理はありません。

## 記録と終了

記録は利用中のブラウザー／Tauri WebViewの保存領域に、キー `pochi.manual.v1` で保存します。C#版の `%LOCALAPPDATA%/PochiDesktop/pochi-data.json` とは別で、自動移行は行いません。保存領域を消すと記録も消えるため、同じブラウザー・オリジン／デスクトップアプリを使ってください。外部への送信やレポートの自動エクスポートは行いません。

作業時間と休憩時間を分離し、ブラウザーのタブ非表示、スリープなど10秒を超えるタイマーの停止、再起動までの時間は加算しません。通常のウィンドウ切り替えではTauriの計時は継続します。異常終了後は前回の記録を「再開」または「終了して記録」で扱えます。

画面の「終了」またはデスクトップウィンドウの閉じる操作で、まずレポートを表示します。デスクトップ版は「保存してアプリを閉じる」で終了します。ブラウザー版はレポートを表示したままにでき、タブを閉じる際にも同期保存します。保存失敗は画面に表示し、保存に失敗している間はデスクトップ版を閉じません。

## 検証と未接続の範囲

```powershell
npm test
npm run build
```

既存の18テストを含めて検証します。今回のTypeScript版は手動の記録フローです。カメラ、PC情報取得、AI通信、自然離席によるレポート生成はこのフローには接続していません。既存の `npm run dev:mock` は、それらの画面開発用の別入口です。
