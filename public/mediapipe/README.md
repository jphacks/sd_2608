# MediaPipe Vision Tasks

Google / MediaPipe, `@mediapipe/tasks-vision` **0.10.35**, Apache-2.0.
Source: https://github.com/google-ai-edge/mediapipe

`npm ci` / `npm run assets:prepare` copies this installed SDK's WASM variants,
SDK README and Apache-2.0 license here. The generated files are ignored by Git
and included in Vite/Tauri builds. There is no runtime CDN fallback.
The npm package declares Apache-2.0 but has no separate LICENSE file, so the
Apache-2.0 text bundled with the face model is also distributed here.
